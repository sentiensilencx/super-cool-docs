Creating your own

  1. Build a document with the styles, placeholder text, and structure you want.
  2. Choose File → Save as template.
  3. Name it, optionally add tags, and choose visibility (private or workspace).

Templates can include table formulas, headers/footers, and page setup — everything except collaborator lists and comment threads.

Placeholders

Wrap any text in double curly braces to make it a placeholder: {{client_name}}. When someone creates a document from the template, Papyra opens a fill-in dialog listing every placeholder. Checklists of pending placeholders appear in the document margin.

Tip
Workspace templates live in Settings → Templates, where admins can pin favorites so they appear first for everyone.
