Self-hosting

Run the entire stack on your own hardware with one Docker command.

Requirements

  • Docker Engine 24+ (or Podman 4+)
  • 2 GB RAM and 1 vCPU minimum for small teams
  • A PostgreSQL 15+ database (bundled in the all-in-one image)
  • A domain with TLS for collaboration features

Quick install

docker run -d \
  --name papyra \
  -p 8080:8080 \
  -v papyra-data:/data \
  -e PAPYRA_SECRET_KEY="generate-a-long-random-string" \
  ghcr.io/papyra/papyra:latest

Papyra is now listening on http://localhost:8080. The first account you create becomes the workspace admin.

Production setup
For real deployments use Docker Compose with a managed Postgres, put TLS in front (Caddy/Nginx), and set PAPYRA_PUBLIC_URL to your HTTPS domain — the collaboration engine needs it to open WebSocket connections.

Docker Compose

services:
  papyra:
    image: ghcr.io/papyra/papyra:latest
    ports:
      - "8080:8080"
    environment:
      PAPYRA_DATABASE_URL: postgres://papyra:pass@db:5432/papyra
      PAPYRA_PUBLIC_URL: https://docs.example.com
      PAPYRA_SECRET_KEY: ${PAPYRA_SECRET_KEY}
    volumes:
      - papyra-data:/data
    depends_on:
      - db
  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: papyra
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: papyra
    volumes:
      - pg-data:/var/lib/postgresql/data
volumes:
  papyra-data:
  pg-data:

Upgrading

Pull the new image and recreate the container. Migrations run automatically at startup and are backwards-compatible with one minor version.

docker compose pull
docker compose up -d
