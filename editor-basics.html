Editor basics

A tour of the canvas, toolbar, outline, and document settings.

The canvas

The canvas is a paginated surface: you see page boundaries, margins, and headers/footers exactly as they will print or export. A live word count, page count, and character count sit in the status bar at the bottom of the screen.

The toolbar

The toolbar groups common formatting actions. It is contextual — selecting an image shows image controls, selecting a table cell shows table controls.

GroupActions
Undo / historyUndo, redo, version history

InsertImage, table, link, footnote, page break, table of contents, code block

Document outline

Open the outline with View → Document outline (or the ☰ icon at the top-left of the canvas). It lists every heading in the document; click one to jump there, and drag headings to restructure entire sections.

Find and replace

Press Ctrl+F for find and Ctrl+H for find & replace. Options include match case, whole words, and regular expressions.

Autosave and versions

Every keystroke is saved locally and synced to the server within seconds. Named versions can be created from File → Version history, where you can preview and restore any earlier snapshot. See Collaboration for how versions interact with co-editing.

Offline mode
Without a connection, edits queue in local storage and sync automatically on reconnect. If you close the tab while offline, Papyra keeps an offline copy — reopen the document from the dashboard to recover it.

Page setup

File → Page setup controls page size, orientation, margins, and default fonts for the document. Changes apply to the whole document unless a section break divides it.
