# super cool docs

A dark, distraction-free, browser-based document editor. Plain HTML, CSS, and JavaScript — no build step, no dependencies.

## Features
- Serif writing canvas with editable title, date, and author line
- Toolbar: new, open (.html/.md/.txt), save, print, cut, copy, bold, italic, underline, lists
- Insert menu: headings, quote, code block, divider, checklist, table, link, image, date
- Editing / Preview modes
- Multiple documents with tabs, stored in localStorage with autosave
- Find & replace (Ctrl/⌘+F)
- Keyboard shortcuts: Ctrl+S download, Ctrl+O open, Ctrl+Alt+N new doc
- Print stylesheet for clean paper output

## Run
Open `index.html` in a browser, or serve statically:
```
python3 -m http.server 8000
```
