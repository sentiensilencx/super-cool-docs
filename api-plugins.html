API & plugins

Extend the editor with custom blocks and automate documents over HTTP.

Plugin architecture

Plugins are sandboxed ES modules registered against the editor. A plugin can add toolbar buttons, custom blocks, and export hooks:

export default {
  name: "math-block",
  blocks: {
    equation: {
      render(el, { latex }) {
        el.innerHTML = katex.renderToString(latex);
      },
      serialize: (node) => ({ latex: node.attrs.latex }),
    },
  },
  toolbar: [
    {
      id: "insert-equation",
      icon: "∑",
      title: "Insert equation",
      run: (ctx) => ctx.insertBlock("equation", { latex: "E=mc^2" }),
    },
  ],
};

Enable plugins per workspace in Settings → Plugins, or sideload a single plugin in dev mode with ?plugins=/my-plugin.js.

REST API

Every self-hosted and cloud workspace exposes a REST API under /api/v1. Authenticate with a personal access token from Settings → API tokens.

curl https://your-instance.dev/api/v1/documents \
  -H "Authorization: Bearer $PAPYRA_TOKEN"
EndpointDescription
GET /documentsList documents (paginated, filterable)
POST /documentsCreate a document from title/content/template
GET /documents/:idFetch a document (JSON or raw)
PATCH /documents/:idUpdate content or metadata
GET /documents/:id/exportExport as docx, odt, pdf, md
GET /documents/:id/commentsList comment threads
POST /webhooksRegister a webhook for doc events

Webhooks

Subscribe to events: document.created, document.updated, comment.created, suggestion.resolved. Deliveries are signed with HMAC-SHA256 and retried with exponential backoff for 24 hours.

Rate limits
The API allows 120 requests per minute per token on self-hosted installs; cloud workspaces scale limits with plan tier.
