Keyboard shortcuts

On macOS, use ⌘ instead of Ctrl and Option instead of Alt. Press Ctrl+/ anywhere to open this cheat sheet in-app.

Essentials

UndoCtrl+Z
RedoCtrl+Y / Ctrl+Shift+Z
Save (force sync)Ctrl+S
Command paletteCtrl+K
Find / Find & replaceCtrl+F / Ctrl+H

Formatting

Bold / Italic / UnderlineCtrl+B / I / U
StrikethroughCtrl+Shift+X
Superscript / SubscriptCtrl+. / Ctrl+,
Clear formattingCtrl+\
Normal textCtrl+Alt+0
Headings 1–4Ctrl+Alt+1…4

Paragraphs and lists

Numbered listCtrl+Shift+7
Bulleted listCtrl+Shift+8
ChecklistCtrl+Shift+9
Increase / decrease indentTab / Shift+Tab
Align left / center / right / justifyCtrl+Shift+L / E / R / J

Insert and navigate

LinkCtrl+K (in selection)
CommentCtrl+Alt+M
FootnoteCtrl+Alt+F
Page breakCtrl+Enter
Document outlineCtrl+Alt+O
