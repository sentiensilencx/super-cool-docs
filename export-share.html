Export & sharing

Get documents out of Papyra — in the format you need, with the fidelity you expect.

Export formats

FormatFidelityNotes
.docxHighStyles, tables, headers/footers, and tracked-changes mapping supported
.odtHighestNative format; live table formulas preserved
.pdfPrint-exactVector text, embedded fonts, optional PDF/A
.htmlMediumStandalone file with inline styles; comments excluded
.mdLossyHeadings, lists, tables, and code blocks; complex layout simplified
.epubGoodFor long-form documents and e-readers

Export from File → Download as, or in bulk from the dashboard (select multiple documents → Export → receive a .zip).

Importing

File → Import or drag-and-drop onto the dashboard. Papyra reads .docx, .odt, .rtf, .html, .md, and plain text. Word comments and tracked changes are imported as native Papyra comments and suggestions.

Publish links

Beyond private sharing, any document can be published: a read-only public page at papyra.dev/p/your-doc with clean typography, your favicon, and optional analytics-off guarantee. Publishing can be revoked at any time and can be password-protected.

Embedding

Published documents can be embedded elsewhere:

<iframe
  src="https://papyra.dev/p/your-doc?embed=true"
  width="100%" height="720"
  style="border:0; border-radius:8px"
  loading="lazy">
</iframe>
Retention
Exports are generated on demand and never stored server-side longer than the download window (1 hour).
