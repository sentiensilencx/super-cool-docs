Tables

Create, structure, and compute inside tables.

Creating a table

Use Insert → Table and drag over the grid to pick a size, or type 3x4 on an empty line and press Tab — Papyra converts it to a 3-column, 4-row table.

Editing structure

Right-click any cell for the full context menu, or use the floating table toolbar:

  • Insert or delete rows and columns (above, below, left, right)
  • Merge and split cells
  • Set header row and header column
  • Distribute rows/columns evenly

Press Tab in the last cell to add a new row automatically.

Formatting

The table toolbar controls cell background, borders, padding, and text alignment. Table-level options include fixed vs. auto column widths and full-page-width sizing.

Formulas

Tables support spreadsheet-style formulas, evaluated on edit. Start a cell with =:

=SUM(A1:A5)
=AVERAGE(B1:B10)
=COUNTIF(A1:A20, ">100")

Supported functions: SUM, AVERAGE, MIN, MAX, COUNT, COUNTIF, ROUND, and cell arithmetic. Formulas recompute when referenced cells change and are recalculated on document load.

Compatibility
When exporting to .docx, table formulas are exported as static computed values, matching Word's behavior. Formulas remain live in Papyra and .odt exports.

Sorting

Select a column and use Table → Sort to reorder rows ascending or descending. Header rows can be excluded from sorting.
