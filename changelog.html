Changelog

All notable changes to Papyra. Follows semantic versioning.

v2.4 — latest

New Improved

  • Table formulas — =SUM, AVERAGE, COUNTIF and friends in table cells.
  • Comment reactions — emoji responses on comment threads.
  • Rewritten DOCX exporter: better list numbering and image anchoring fidelity.
  • Command palette learns from usage; most-recent actions rank first.

v2.3

  • Suggesting mode — tracked suggestions with accept/reject flow.
  • Templates with placeholders — {{fill_in}} fields with a fill-in dialog.
  • Markdown import now preserves nested task lists.

v2.2

  • Plugin API 1.0 — custom blocks, toolbar extensions, export hooks.
  • Document outline: drag headings to restructure sections.
  • Expiring share links on self-hosted instances.

v2.1

  • Offline mode — full offline editing with queued sync.
  • PDF/A export option for archival documents.
  • Right-to-left interface layouts (Hebrew, Arabic, Persian).

v2.0

  • Ground-up rewrite of the collaboration engine on CRDTs — concurrent edits in the same paragraph merge cleanly.
  • New default theme, paginated canvas, and status bar.
  • REST API and webhooks GA.

Older releases are archived on the GitHub releases page.
