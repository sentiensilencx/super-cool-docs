Collaboration

Real-time co-editing, comments, suggestions, and access control.

Real-time co-editing

Every collaborator's cursor is labeled with their name and color. Edits propagate in under 100 ms, and a CRDT-based sync engine merges concurrent edits without locking the document — two people can type in the same paragraph at the same time.

Sharing

Click Share to manage access. You can invite by email or create a link with a fixed role:

RoleCapabilities
ViewerRead only; can download a copy
CommenterRead + comment + suggest
EditorFull editing; can share further if allowed
OwnerEditor + delete, transfer ownership, manage access

Link sharing can be restricted to your workspace domain or turned off entirely. Expiring links (7/30/90 days) are available on self-hosted plans.

Comments

Select text and press Ctrl+Alt+M (or the comment icon) to anchor a comment. Threads support:

  • @mentions — mentioned users get a notification
  • Reactions and emoji responses
  • Resolve/reopen, with a full resolved-comment archive
  • Assigning a thread to a person as a to-do

Suggesting mode

Switch your role to Suggesting (top-right, next to your avatar). Edits become tracked suggestions the document owner can accept or reject individually, or all at once from the review sidebar.

Version history

File → Version history shows every autosave plus named versions. You can:

  • Preview any version with per-author color coding
  • Restore an old version (the current one is kept as a named version first)
  • Name milestones like “Draft for legal review”
Restores are document-wide
Restoring a version replaces the whole document for all collaborators. Communicate before rolling back a shared doc.
